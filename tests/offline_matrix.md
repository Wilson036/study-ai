# 離線狀態矩陣

每格填「日期 / 裝置 / 操作 / 實際結果 / 通過與否」。

| 情境 | 預期結果 | 實測 |
|---|---|---|
| 首次未登入即離線 | 顯示設定引導，無法憑空取得私有題庫，不白屏 | 待測 |
| 曾載入後離線 | 可完整練習；顯示離線與待上傳數 | 待測 |
| 瀏覽器被殺後飛航重開 | 從 local profile、active bank pointer 與事件恢復 | 待測 |
| JWT 過期且離線 | 練習不中斷，同步停用且不清資料 | 待測 |
| refresh 失敗 | 顯示需重新登入；本機進度保留 | 待測 |
| Service Worker 更新失敗 | 沿用現有 shell；不打斷作答 | 待測 |
| 新 shell 配舊題庫 | schema 相容則使用；不相容顯示重載提示 | 待測 |
| 離線登出 | 保留本機資料，下次可恢復 | 待測 |
| iOS 清除網站資料 | 明確顯示資料已不在；登入後由伺服器或匯入檔復原。不得以「資料仍在」判綠 | 待測 |
